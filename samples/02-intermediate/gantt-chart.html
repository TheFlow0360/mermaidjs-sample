Project timeline with task dependencies and milestones

Website Redesign Project

This Gantt chart visualizes a software project timeline showing tasks, their duration, dependencies, and critical path. It's useful for project planning, resource allocation, and tracking progress across multiple phases.

Key Features

  • Time-based task scheduling
  • Task dependencies and sequencing
  • Milestone markers
  • Parallel and sequential tasks
  • Duration visualization

Mermaid Syntax

gantt
    title Website Redesign
    dateFormat YYYY-MM-DD

    section Planning
    Requirements :req, 2024-01-01, 14d
    Design Review :des, 2024-01-15, 10d

    section Development
    Frontend :fe, after des, 20d
    Backend :be, after des, 25d

    section Testing
    QA :qa, after fe be, 15d
    Launch :milestone, after qa, 1d
